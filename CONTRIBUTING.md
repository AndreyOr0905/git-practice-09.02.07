# Contributing Guide

Используйте спецификацию [Conventional Commits](https://conventionalcommits.org).

### Шаблон:
`тип(контекст): описание`

### Типы коммитов:
- **feat:** Новая функция (пример: `feat(calc): добавить корень`)
- **fix:** Исправление бага (`fix(calc): деление на 0`)
- **docs:** Документация (`docs: добавить changelog`)
- **chore:** Настройки CI/CD или сборки
